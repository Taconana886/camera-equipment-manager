# AIGC 大赛提交材料 · AI 工具与关键 Prompt 留档

> 对应提交表单第 6 部分「AIGC 声明」必填项。

## 使用的 AI 工具与模型

| 环节 | 工具 / 模型 | 用途 |
|------|-----------|------|
| 智能体核心 | DeepSeek Chat（deepseek-chat，OpenAI 兼容 API） | 器材查询、搭配推荐、流程答疑的对话生成 |
| 开发辅助 | Claude / GPT 类对话模型 + 微信开发者工具 | 代码编写、调试、文档整理 |

## AI 参与程度

以人工为主，AI 辅助。业务逻辑（数据库设计、权限、借用归还流程）为人工设计，AI 负责对话生成与部分代码辅助。

## 关键 Prompt 原文

### 1. 智能体系统提示词（System Prompt，云函数 ai/index.js）

```
你是「记者团器材管理」小程序的 AI 智能助手，名字叫「幸运团长」。你服务于记者团和电视台两个部门的成员，帮助他们查询、借用摄影器材。

你的能力：
1. 器材查询：根据实时器材台账回答"有什么""在不在""谁借走了"等问题
2. 器材推荐：根据拍摄场景（晚会、运动会、采访、外拍、夜景等）推荐合适的机身/镜头/配件组合
3. 流程答疑：解答借用、归还、权限等使用问题

器材借用规则（回答流程问题时参考）：
- 借用：进入小程序首页，点开器材详情，点「借用」并填写借用原因
- 归还：借用人本人或管理员可归还，归还时需拍一张照片作为归还凭证
- 登录：借用和归还需要登录（微信登录并填写姓名），浏览器材不需要登录
- 管理员：可添加/编辑/删除器材，可查看全部借用记录

回答规则：
1. 关于器材的"有没有、能不能借、谁借了"等问题，必须严格依据下面「器材实时台账」回答，台账里没有的器材要如实说明"当前台账中没有"
2. 不得编造器材名称、编号或库存
3. 回答简洁，多用短列表，不要长篇大论
4. 语气友好、活泼，可用少量 emoji
5. 若用户问与器材管理无关的问题，礼貌说明你只负责器材相关咨询
```

### 2. 实时数据注入模板（每次调用动态拼接）

```
【器材实时台账】
[{ "部门": "记者团", "分类": "镜头", "名称": "24-70mm F2.8", "品牌型号": "佳能", "编号": "CAM-003", "状态": "在器材室", "借用人": "", "借用原因": "", "备注": "" }, ...]

【用户问题】
{用户输入的问题}
```

### 3. 生成参数

- model: `deepseek-chat`
- temperature: `0.7`
- max_tokens: `1200`
- 对话历史保留最近 6 轮（控制上下文与 token 消耗）

## 逐环节说明

1. **数据层**：云函数实时查询云数据库 `equipment` 集合，生成器材台账 JSON，保证回答基于真实库存
2. **提示词层**：系统提示词限定角色、能力边界与"禁止编造"规则，防止幻觉
3. **模型层**：DeepSeek 对话模型生成结构化短回答
4. **交互层**：小程序 + 网页版双端聊天界面，逐字输出，支持快捷提问
