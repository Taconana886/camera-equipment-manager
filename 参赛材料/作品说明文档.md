## 一、作品概述

「幸运团长」是嵌入「记者团器材管理」小程序的 AI 智能助手。记者团与电视台的成员通过自然语言向它提问，即可实时查询器材库存、获取拍摄器材搭配推荐、了解借用归还流程，让传统"翻列表找器材"变成"一句话搞定"。

本作品不是演示 Demo：**小程序已正式上线运行**，服务大连理工大学盘锦校区记者团、电视台两个部门的真实成员，管理上百件摄影器材与全部借用记录。AI 助手基于云数据库实时台账回答，做到"所见即所得、所答即所存"。

## 二、需求洞察

### 2.1 真实痛点

记者团器材管理此前存在三类问题：

| 痛点 | 具体表现 |
|------|---------|
| 查询低效 | 成员借用前要逐条翻列表确认"在不在、谁借了"，器材多时耗时费力 |
| 搭配无门 | 新手成员不知拍晚会/运动会该借哪些器材组合，只能凭感觉或问学长 |
| 流程询问重复 | "怎么借""怎么还""要登录吗"等高频问题反复打扰管理员 |

### 2.2 需求验证

- 器材数据真实：包含部门、分类、编号、品牌、状态、借用人、借用原因等字段
- 借用流程真实：登录 → 浏览 → 借用（填原因）→ 归还（拍照凭证），全流程线上完成
- 智能助手上线后，成员查询类问题可直接由 AI 回答，管理员重复答疑工作量显著减少

## 三、智能体设计

### 3.1 角色设定

- **名字**：幸运团长
- **定位**：记者团/电视台成员的器材管理 AI 助理
- **能力边界**：器材查询、搭配推荐、流程答疑；与器材管理无关的问题礼貌拒绝

### 3.2 核心机制：实时台账注入（RAG-Lite）

普通聊天机器人容易"一本正经地胡说"。幸运团长采用**实时数据注入**方案：

```
用户提问
   │
   ▼
云函数 ai（微信云开发）
   ├─ 1. 实时查询云数据库 equipment 集合
   ├─ 2. 生成「器材实时台账」JSON（部门/分类/名称/型号/编号/状态/借用人/原因）
   ├─ 3. System Prompt（角色+规则）+ 台账 + 用户问题 → DeepSeek
   └─ 4. 返回结构化回答
```

每次问答都基于**当下最新**的库存状态，器材刚被借出/归还，下一次问答立即反映，杜绝幻觉。

### 3.3 提示词工程（防幻觉规则）

系统提示词中的关键约束：

1. 器材"有没有、能不能借、谁借了"必须严格依据实时台账回答，台账没有的如实说明
2. 不得编造器材名称、编号、库存
3. 回答简洁，多用短列表
4. 语气友好活泼，符合大学生群体

（完整 Prompt 原文见《AIGC声明-关键Prompt留档》）

### 3.4 能力清单

| 能力 | 示例提问 | 智能体行为 |
|------|---------|-----------|
| 器材查询 | "有哪些镜头可以借？" | 按台账列出在库镜头及编号型号 |
| 状态追踪 | "闪光灯谁借走了？" | 返回借用人、借用原因 |
| 搭配推荐 | "推荐一套拍运动会的组合" | 结合在库情况推荐机身+镜头+配件，标注哪些暂不可借 |
| 流程答疑 | "怎么借器材？" | 按规则说明登录/借用/归还/拍照凭证流程 |

## 四、系统架构

```
┌─────────────────────────────────────────────┐
│               用户端（双端）                    │
│  微信小程序（正式上线）  │  网页版（静态托管）      │
└──────────────────┬──────────────────────────┘
                   │ wx.cloud.callFunction / CloudBase SDK
                   ▼
┌─────────────────────────────────────────────┐
│            微信云开发（云端）                    │
│  ├─ 云函数 ai（智能体核心）                     │
│  │    · 查台账 → 拼 Prompt → 调 DeepSeek      │
│  ├─ 云函数 login/equipment/borrow/admin/init │
│  ├─ 云数据库：users / equipment / borrow_records│
│  └─ 云存储（器材图片、归还凭证）                   │
└──────────────────┬──────────────────────────┘
                   │ HTTPS
                   ▼
        DeepSeek 大模型 API（deepseek-chat）
```

- **身份认证**：小程序微信 OpenID；网页版 token（双端已打通）
- **权限**：首个注册用户自动成为管理员；借用/归还需登录
- **数据**：全部云端存储，多端实时同步

## 六、创新点

1. **真实落地而非演示**：已上线服务真实用户，数据、流程、权限体系完整
2. **实时台账注入防幻觉**：AI 回答绑定数据库当前状态，不编造、可追踪
3. **双端一致体验**：小程序与网页版共用同一智能体，评委可零门槛体验
4. **低成本可持续**：云开发免费额度 + DeepSeek 极低成本（单次问答约 0.001~0.005 元）
5. **业务规则内化**：借用/归还/权限规则写入提示词，答疑与系统行为一致
