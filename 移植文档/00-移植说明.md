# 移植说明（新笔记本部署指南）

本文件夹是「记者团器材管理」小程序的完整项目。移植到新笔记本只需 4 步。

## 一、关键前提：数据在云端，不在本机

你的器材数据、用户、借用记录、图片，**全部存在微信云端**，不随文件夹迁移。

所以换笔记本后，**不需要重新建数据库、不需要重新传数据**，只要用**同一个微信账号**登录微信开发者工具，就能看到原来的全部数据。

## 二、移植步骤

### 第 1 步：复制文件夹

把整个 `camera-equipment-manager` 文件夹复制到新笔记本（U 盘、网盘、GitHub 都可以）。

### 第 2 步：安装微信开发者工具

下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

装「稳定版 Stable」即可。

### 第 3 步：导入项目

1. 打开微信开发者工具，用**注册小程序的微信**扫码登录（必须是同一个微信！）
2. 点「导入项目」，选择 `camera-equipment-manager` 文件夹
3. AppID 会自动识别（已在 `project.config.json` 里配置好）
4. 导入后，代码就能看到、能改

### 第 4 步：确认环境配置

打开 `miniprogram/app.js`，确认这一行的环境 ID 正确：

```js
wx.cloud.init({
  env: 'cloud1-d5gjwi2eze187d7e6',
  traceUser: true
})
```

这个环境 ID 已经填好了，一般不用改。

## 三、云函数和云端数据（重要）

| 内容 | 在哪 | 换笔记本后 |
|------|------|-----------|
| 云函数（login/equipment/borrow/admin）| 云端 | ✅ 不用重新部署，直接能用 |
| 数据库（器材/用户/记录）| 云端 | ✅ 数据都在 |
| 云存储（图片）| 云端 | ✅ 都在 |
| 小程序前端代码 | 本机文件夹 | 需要复制过来 |

**只有改了云函数代码，才需要重新「上传并部署」云函数；只改前端，点「上传」就行。**

## 五、常见问题

- **导入后 AppID 不对**：点「详情」→「基本信息」→「修改」，填 `wx472b1a23e41bfd51`
- **云函数调用失败**：确认 app.js 的环境 ID 正确，且云函数已部署（云端有）
- **看不到数据**：确认登录的是同一个微信
