# 记者团器材管理小程序

基于微信小程序 + 微信云开发（云函数 + 云数据库 + 云存储）实现的摄影器材管理系统，适用于记者团/摄影社团的器材借用管理。

## 功能

- **器材管理**：管理员可添加、编辑、删除器材，支持名称、编号、品牌型号、图片、备注
- **借用登记**：用户通过个人微信登录并填写姓名，借用器材后自动记录借用人
- **状态标注**：器材自动标注「在器材室」或「已借出」，已借出显示借用人姓名
- **归还**：借用人本人或管理员可归还器材
- **多管理员**：首个注册用户自动成为管理员，可添加其他成员为管理员协助管理

## 技术栈

- 微信小程序（原生 WXML/WXSS/JS）
- 微信云开发：云函数、云数据库、云存储

## 数据库集合设计

| 集合 | 说明 | 关键字段 |
|------|------|----------|
| `users` | 用户 | `name`(姓名)、`isAdmin`(是否管理员)、`createTime` |
| `equipment` | 器材 | `name`、`code`(编号)、`brand`、`imageFileID`(图片)、`remark`、`status`(available/borrowed)、`currentBorrower`、`currentBorrowerOpenid`、`borrowTime` |
| `borrow_records` | 借用记录 | `equipmentId`、`equipmentName`、`borrowerName`、`borrowerOpenid`、`borrowTime`、`returnTime`、`status` |

## 部署步骤

### 1. 注册小程序账号

前往 [微信公众平台](https://mp.weixin.qq.com/) 注册小程序（个人主体即可），获取 **AppID**。

### 2. 导入项目

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开微信开发者工具 → 导入项目，选择本项目根目录
3. 在 `project.config.json` 中将 `appid` 字段替换为你的 AppID（`touristappid` 仅用于体验测试，无法使用云开发）

### 3. 开通云开发

1. 在开发者工具中点击工具栏「云开发」按钮
2. 开通云开发环境（免费额度即可），记录下 **环境 ID**（形如 `camera-xxxx`）
3. 将 `miniprogram/app.js` 中 `wx.cloud.init` 的 `env` 字段填入你的环境 ID：

```js
wx.cloud.init({
  env: '你的环境ID',  // 例如 'camera-xxxx'
  traceUser: true
})
```

### 4. 部署云函数

在开发者工具中，对 `cloudfunctions` 目录下的每个云函数文件夹（`login`、`equipment`、`borrow`、`admin`、`init`），右键选择「上传并部署：云端安装依赖」。

### 5. 初始化数据库集合

1. 在开发者工具中右键 `init` 云函数 → 「云端测试」，直接运行
2. 或打开云开发控制台 → 数据库，手动创建以下三个集合：
   - `users`
   - `equipment`
   - `borrow_records`

> 集合权限建议保持默认（「仅创建者可读写」）。所有数据读写都通过云函数完成，云函数拥有管理员权限，不受集合权限限制。

### 6. 云存储权限（图片显示）

图片上传到云存储后，默认「仅上传者可读」，会导致其他成员看不到图片。需在云开发控制台修改：

1. 云开发控制台 → 左侧「存储」
2. 「权限设置」→ 改为「所有用户可读，仅创建者可写」
3. 保存即可

## 使用说明

### 首次使用（成为管理员）

1. 编译运行小程序，进入登录页
2. 填写你的姓名并登录
3. **第一个注册的用户会自动成为管理员**（`users` 集合为空时）

### 添加器材（管理员）

1. 首页点击右上角「⚙ 管理」进入管理后台
2. 在「器材管理」标签点击「＋ 添加器材」
3. 填写名称（必填）、编号、品牌型号、上传图片、备注
4. 保存后即可在首页看到，默认状态为「在器材室」

### 借用器材

1. 成员通过微信登录并填写姓名
2. 首页点击器材进入详情
3. 点击「借 用」，确认后该器材被标记为「已借出」并记录借用人姓名

### 归还器材

- 借用人本人在详情页点击「归 还」
- 管理员可归还任意被借出的器材

### 添加管理员

1. 管理员进入「管理后台」→「用户管理」
2. 找到目标成员（需先登录注册过），点击「设为管理员」

## 常见问题

- **没有「管理」按钮**：当前账号不是管理员。检查是否首个注册，或在云开发控制台 `users` 集合中手动将对应记录的 `isAdmin` 字段改为 `true`。
- **云函数调用失败**：确认已上传部署云函数，且 `app.js` 中 `env` 填写正确。
- **图片看不到/别人看不到**：云存储默认「仅上传者可读」，需在控制台「存储」→「权限设置」改为「所有用户可读」。
- **设为管理员后对方仍显示普通成员**：对方本地缓存了旧身份，重新进入小程序首页即可自动刷新（已支持）。
- **无法借用**：提示「请先登录并填写姓名」，确认已通过登录页注册。
