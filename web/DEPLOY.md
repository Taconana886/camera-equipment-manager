# 网页版部署说明

记者团器材管理（网页版）部署步骤。

## 一、部署云函数（4 个都改了，必须重新部署）

在微信开发者工具中，对以下 4 个云函数逐个右键 →「上传并部署：云端安装依赖」：

- `login`
- `equipment`
- `borrow`
- `admin`

> `init` 云函数不用重新部署（没改）。

## 二、开通静态网站托管

1. 开发者工具点「云开发」进控制台
2. 左侧「**静态网站托管**」
3. 点「**开通**」（免费额度即可）
4. 开通后，把 `web/` 目录下的这 3 个文件**上传到托管根目录**：
   - `index.html`
   - `style.css`
   - `app.js`

上传方式：控制台「静态网站托管」页面有「上传文件」按钮，把 3 个文件拖进去（保持文件名，放在根目录）。

## 三、获取网址

上传后，控制台会显示一个**默认域名**（形如 `xxx.tcloudbaseapp.com`，HTTPS）。

浏览器打开这个网址，就能看到网页版了。这就是你的正式网址。

## 四、首次使用（注册管理员）

1. 打开网址 → 填姓名 + 密码 → 点「立即注册」→「注 册」
2. **第一个注册的用户自动成为管理员**

> 如果你之前在小程序里注册过（用了同样的姓名），网页版注册时会自动「接管」旧账号、保留管理员身份。

## 五、NFC 贴片

1. 买 NTAG215/213 空白贴片
2. 用手机 App「NFC Tools」把上面那个网址写进贴片
3. 贴在器材柜/器材上
4. 成员手机碰一下 → 打开网页，浏览器材、登录借用

## 六、安全注意

- 网页版是**公开可访问**的，任何人都能打开浏览器材列表（无需登录）
- 但**借用、管理操作必须登录**（姓名+密码）
- 密码存的是加密后的哈希，不是明文

## 七、后续修改代码

每次改了云函数或前端代码后：

1. 云函数改动 → 重新「上传并部署」
2. 前端改动 → 重新上传 `web/` 的 3 个文件到静态托管（覆盖）
